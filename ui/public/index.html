Compiled Binary Database & Sentinel Watchdog

Zero plaintext JSON storage, memory-mapped WAL transactions, and continuous integrity audits.

Zero Plaintext JSON

Credentials, OAuth tokens, and accounts are binary-masked and stored as compiled C BLOBs. No raw JSON files can be inspected or leaked.

32-Bit CRC32 Sealing

Every stored record is cryptographically stamped with a CRC32 checksum. Any external hex tampering is caught instantly upon load.

Sentinel Watchdog & WS

An autonomous background thread audits the physical binary file every 5 seconds, piping status and logs via WebSocket (/ws/live).

Helpdesk, FAQ & Troubleshooting

Quick solutions to common operational and account management questions.

Q: How do I delete or remove accounts via Terminal flags or Web UI?

In Web UI: Open the Account Manager tab. Click the red Delete button next to any configured account, or click Delete Account on the Active Identity card. To wipe all accounts, click Clear All.
In Terminal: Use flexible flags: prime-gate auth remove --email user@gmail.com --force prime-gate auth remove --all --force prime-gate delete-account -e user@gmail.com

Q: How often does Google Antigravity reset model quotas?

Google Antigravity quotas operate on a rolling daily window. In the Web UI Dashboard and Quota Radar, each model bucket displays its exact reset timestamp (typically between 2 to 24 hours depending on the model tier).

Q: What happens if port 52111 or 52110 is already in use?

You can specify custom ports when starting Prime Gate. For instance: prime-gate start --port 52120 and prime-gate ui --port 52121 --api-port 52120.

Q: Why did I receive a 503 "MODEL_CAPACITY_EXHAUSTED" error?

This occurs when requesting overloaded upstream models like legacy Gemini 2.5. Switch to gemini-3.8-flash or claude-sonnet-4-6, which have high dedicated capacity.

Q: Where is my data saved, and is it safe to commit to Git?

All credentials, models, and quotas are saved into the compiled binary database data/prime_gate.pgdb, which is excluded by .gitignore. Your Git repository remains 100% clean with zero plaintext credentials or tokens.
